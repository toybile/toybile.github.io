# Shared appearance window

Bundled from toybile/toybile-s-Default-Configurations (private source), commit f5f55a94e3415c507065a00d5f46483d2dfe04c6. Source controls, collapsible sections, scrolling and motion are preserved. Shadow DOM isolates the component from host app styles and data attributes. Host adapters preserve native language, palettes, translucency and Atlas zoom. No remote runtime dependency on the private repository.
