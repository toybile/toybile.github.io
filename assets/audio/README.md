# Portfolio sound effects

Chess uses the original Chess.com default recordings, downloaded from the official asset host:

- Movement: https://images.chesscomfiles.com/chess-themes/sounds/_MP3_/default/move-self.mp3
- Capture: https://images.chesscomfiles.com/chess-themes/sounds/_MP3_/default/capture.mp3

The Steins;Gate animation recording is preserved byte-for-byte in worldline-original.mp3. A 125 ms button beep, isolated from Kaito Cross’s PhoneWave demonstration, plays only on the first two touches at gain 0.20. Source: https://www.youtube.com/watch?v=VbQfQ6UQSwk (85.665–85.790 s); the author identifies the button effects as samples from the anime. Urn keypad and private-unlock effects are synthesized; the existing urna-confirmacao.mp3 remains the voting confirmation. All playback follows interaction and can be muted.

Chess king artwork: https://images.chesscomfiles.com/chess-themes/pieces/neo/150/bk.png
The hand, chessboard and animation are original code-native artwork.
