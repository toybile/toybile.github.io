## Run and update

Open index.html in a modern browser. No dependencies are required. GitHub Pages publishes the root of the main branch; push updated files to that branch to update the website.

- index.html: main menu.
- lp/index.html: complete Propositional Logic editor.
- .nojekyll: static file publishing.

LP arguments and preferences are stored locally in the browser using localStorage. They do not sync between devices or website addresses. Clearing site data removes them; export important arguments.
